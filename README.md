# Selenium WebDriver with PyTest Automation Portfolio

This repository contains my daily practice files, test scripts, and automation frameworks as I master Selenium and PyTest.

## 🛠️ Tech Stack & Tools
* **Language:** Python
* **Framework:** PyTest
* **Automation:** Selenium WebDriver
* **IDE:** PyCharm

## 🚀 How to Run the Tests
1. Install dependencies: `pip install selenium pytest`
2. Run all tests: `pytest`
